about catnet.

a very small internet.

catnet is a complete little internet that lives on one ESP32 microcontroller and a USB power bank. there is no connection to the outside world — everything here (chat, files, the arcade, these words) is served from a chip with about 520 KB of memory and 4 MB of flash.

join the wi-fi, open http://catnet.lan or 192.168.4.1, and you're in.

meet tuft

tuft is catnet's resident cat and, technically, the entire IT department. every animation comes from one 320×576 sprite sheet: four frames, eight moods.

what's here

  • chat — the living room. live-ish (it checks every second and a half).
  • board — slower conversations that stick around.
  • files — share things; public files double as your homepage at /~yourname/.
  • notes — private notes, only you can read them.
  • arcade — DENIED., SIGNAL and nine lives. games run in your browser; saves and high scores live on catnet.

honest security notes

catnet takes security seriously for a cat, but a microcontroller is not a bank:

  • the wi-fi uses WPA2, but the web pages use plain http. anyone who knows the wi-fi password can, with effort, sniff traffic on the air. don't reuse an important password here.
  • passwords are stored salted and hashed (PBKDF2-SHA256), sessions use random 128-bit tokens bound to your device's address, and every change needs a per-session anti-forgery token.
  • public files can be opened by anyone on the wi-fi. private files are visible to you and to admins.
  • admins can read the event log and moderate chat, the board and files.
  • game scores are reported by your browser, so a determined cheater can cheat. it's a cat arcade.
